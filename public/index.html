Concept

What this frontend proves

REST Over-fetching

REST often returns a fixed JSON shape. The UI may only need title and availability, but the endpoint still returns ISBN, pages, timestamps, description, and IDs.

REST Under-fetching

When the UI needs a book with author and category details, REST may require multiple calls: book, author, and category.

GraphQL Query

GraphQL lets the frontend request exactly the fields it needs in one query: book title, author name, category name, and availability.

Mutation

Both REST POST and GraphQL mutation can create a book. The demo shows how the write operation looks in each API style.
