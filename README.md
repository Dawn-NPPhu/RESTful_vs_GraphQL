# API Design: RESTful vs GraphQL
**Topic 3 - Web Programming & Applications (503073) - Midterm Essay**

Dự án cung cấp cái nhìn tổng quan, so sánh chi tiết và mã nguồn thực tế triển khai hai kiến trúc API phổ biến nhất hiện nay: **RESTful API** và **GraphQL**.

---

## 🚀 Quick Start & Setup

**Yêu cầu hệ thống:** Node.js v14+ và npm.

```bash
# 1. Cài đặt thư viện
npm install

# 2. Chạy cả 2 server cùng lúc (RESTful: port 3001 | GraphQL: port 3002)
npm run dev:both

# 3. Chạy demo test hiệu năng và so sánh
Frontend Dashboard (Demo): http://localhost:3001
REST API Base URL: http://localhost:3001/api
GraphQL Sandbox: http://localhost:3002/graphql
